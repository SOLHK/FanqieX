# FanqieX 1.9.6beta5 测试版

本版基于 1.9.6beta4，Mach-O 构建标识为 `0x15605`。

- **短剧**　长按播放选项与分享面板采用同一类原生清透液态玻璃。额外模糊设为 0 时移除附加模糊层，正值直接按所选百分比应用。设置位于「短剧 → 播放设置」。
- **书架**　「历史」恢复宿主横向切页动画。分页状态补偿等转场完成后再执行。
- **我的**　冷启动时应用金币与福利卡片开关，同时清理快捷卡页码区域的实色底条，让四个按钮与分页圆点保持对齐。

使用现有 IPA 注入和重签名流程，将原有 FanqieX 动态库替换为 `FanqieX-1.9.6beta5.dylib`。同一个宿主只加载一份 FanqieX。

验证状态记录为 `device_tested: false`，待 iPhone 验证入口、分页和面板显示。
