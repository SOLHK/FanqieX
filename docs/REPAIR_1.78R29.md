# FanqieX 1.78R29 本地测试版

适用番茄小说 7.4.3（7.4.3.33）。本次对应四张设备截图，未推送 GitHub、未触发 CI。

## 修改

- Telegram 频道移到插件设置首页，位于大分类列表下方；从“诊断与其他”移出，链接和原动作保留。
- 隐藏“观看完整漫剧／全集”胶囊右侧外露的箭头，仅针对对应剧集入口。原著等其他入口的箭头保留，关闭玻璃或控件复用时恢复原状态。
- 详情播放器的返回、更多、原著整条、选集整条及右侧清屏小按钮增加液态玻璃。保留原生点击、手势、回调和控件位置。
- 修复设置子页面中的日志导出路由：从旧设置控制器关联的菜单取得当前可见页面，作为生成日志和弹出分享面板的接收者。
- 搜索未激活时直接执行按钮动作，避免等待没有实际退出过程的搜索关闭回调；激活搜索时仍先退出搜索再执行。

日志问题的两个分支已用旧包复现：隐藏旧设置页且找不到其导航时静默退出；搜索未激活却持有 presenter 时原按钮动作可能一直等待 dismiss completion。这是明确状态下的代码回归，不等于已捕获用户设备当时的内部状态。

## 验证

- ARM64 iOS 编译、单库链接及加载结构／签名页哈希检查。
- UI 专项执行实际 ARM64：箭头隐藏与恢复、控件复用、玻璃开关恢复；返回、更多、原著、选集及清屏控件的原 frame、target/action、delegate 和回调保持。
- 最终合并库的实际菜单动作分发覆盖日志导出和模拟领取的 8 种搜索状态；实际 ARC 可见控制器 helper 覆盖 3 种关联状态。
- 日志专项执行原导出处理、工作队列、JSON 生成和主线程分享回调，检查按钮恢复、busy 状态清理及弹出锚点。
- 本次代码达到扩展容量上限，R29 单独增加一个 16 KiB 页；旧版本限制保持原值。容量、页签名及越界拒绝的 4 项检查通过。

Foundation/UIKit 和系统队列仍是离线模型边界；没有连接 iPhone，不把这些结果当作真实玻璃渲染或系统分享面板验收。实际结果和候选哈希见 `VERIFICATION.json` 与 `verification/`。

## 安装与检查

替换旧插件，注入 ZIP 内唯一的 `FanqieX-1.78R29.dylib` 并重新签名。

1. 插件设置首页查看 Telegram 频道。
2. 信息流中查看“观看完整漫剧”右侧箭头是否消失。
3. 进入全集详情，检查返回、更多、原著、选集及清屏按钮的玻璃效果与点击。
4. 诊断与其他 → 导出日志，应在生成文件后显示系统分享面板；也可搜索“导出日志”后执行。
