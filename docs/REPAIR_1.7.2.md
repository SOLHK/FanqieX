# FanqieX 1.7.2 本地测试版

修复番茄小说首页顶部横向分类导航文字叠加问题。

- 分类导航继续完全由宿主原生布局、裁剪、文字和切换动画负责，不安装分类视图玻璃 Hook。
- 移除 `resetTopTabSearchViewWithRatio:` 的玻璃更新 Hook，避免在顶部分类交互过渡期间反复更新搜索背景材质。
- 搜索栏玻璃只在页面布局和显示阶段更新，不再跟随分类切换进度逐帧执行。
- 保留首页搜索栏玻璃、书架按钮玻璃、阅读页控件、去广告规则及诊断功能。

回归检查覆盖分类栏原生布局、重复 layout、搜索栏玻璃恢复，以及现有 ARM64 二进制测试。离线模型不能代替真实 iPhone 渲染验收；最终仍需检查长短分类名称、横向滑动、快速切换及页面返回。

Xcode 27.2 重新生成的 ARM64 组件已提交到 test；离线验证使用该生成结果，避免不同 Clang 版本产生不同 unwind 元数据。
构建顺序：先由 Xcode 27.2 从 `native/AlignedGlass.m` 生成并提交 `native/AlignedGlass.s`，再对包含该生成文件的提交执行 Linux ARM64 回归、双重重建和插件打包；不接受跨提交混用的构建产物。
