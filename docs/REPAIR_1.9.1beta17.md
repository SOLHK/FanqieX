# FanqieX 1.9.1beta17

基于 `test` 分支的 1.9.1beta16 修复模糊调节、短剧顶部分段按钮和「我的」快捷入口。

## 模糊调节

- Dock、短剧/小说评论区、短剧顶部模糊使用 0–100 的整数百分比。滑杆吸附整数，新增每次加减 1% 的按钮，VoiceOver 调整同样为 1%。显示、保存和效果插值使用同一数值。
- 效果进度直接使用 `百分比 / 100`，移除原来的平方映射。每一步对应 0.01 的插值进度；这不意味着不同背景下人眼感受到的模糊量完全相同。
- 评论面板的布局会禁止隐式动画，现在在布局事务结束后创建模糊插值器，避免小百分比直接得到完整材质。移出窗口、再次展示及回到前台后重新绑定当前窗口的效果。
- Dock 同时适配原生 platter 和 iOS 兼容布局中的背景 `UIVisualEffectView`，更新实际显示的背景。原生标签选择、图标及手势继续由原有交互路径处理。
- 高斯评论材质直接调整主模糊层，避免在固定强度的高斯背景上再叠一层模糊。
- 液态玻璃的 0% 关闭附加模糊，保留玻璃本身的边缘、折射和原有可读性底色；不通过降低整个控件透明度来冒充模糊调节。

## 短剧顶部选中层

顶部容器明确发布自己的玻璃底板与原有选中层，交互模块按对象引用接管。移除按子视图顺序猜测选中层的逻辑，避免把新增模糊层认作选中层。交互胶囊存在时，原有选中层保持不可见；关闭玻璃或替换容器时归还状态。保留按压折射、拖动选中与松手回弹。

## 「我的」快捷入口

修正快捷卡片的裁切和集合布局之间的冲突，按钮、分页及红点应留在各自的可见区域内。保留原有数据源、点击动作和后续页面入口。

## 构建与版本

beta16 的 Apple 编译输出比历史修补区域上限多 1,200 字节，导致 `Extension bounds`。beta16/beta17 的区域增加一个 16 KiB 页至 `0x64000`，同步签名、独立结构审核和边界检查。旧版本的容量限制保持原值。

beta17 的版本字为 `0x15111`；诊断日志、构建入口及插件名统一为 `1.9.1beta17`。同一提交的 Xcode 完整集成产物通过审核后再打包，不将仅含核心的 dylib 当作完整插件。

完整模块集成另修复两处构建问题：

- Apple 链接器生成的 `__DATA` 零初始化区跨入额外一页，造成 `__LINKEDIT` 的文件偏移与虚拟地址相差 `0x4000`。合并器按实际文件偏移读取链接信息，保留零填充空间，再按虚拟地址放置核心代码；段权限、指针、初始化、异常展开与签名校验继续执行。
- 两次导出模块链接偶发生成不同的 `objc_msgSend` 跳转槽顺序。Apple 构建使用官方支持的 `-objc_stubs_small`，让选择器跳转共享普通消息调用入口，继续要求两次独立构建逐字节一致。该选项保留消息调用语义，使用更小的跳转代码；其大小与跳转开销取舍见 [Apple WWDC22 说明](https://developer.apple.com/videos/play/wwdc2022/110363/)。

## 验证范围

- 本地百分比检查遍历全部 101 个整数值、正反向一步进、四舍五入与 0/100 边界。
- GitHub Xcode 工作流编译完整 UIKit 模块并运行已有原生检查，Linux 工作流审核同一提交的 Apple 构建产物、签名及相关功能。
- UIKit 的实际折射、按压动画和宿主真机页面效果仍需安装后确认。建议依次检查 0%→1%→2%、100%→1%、明暗切换、评论面板关闭重开、短剧顶部连续切换和快捷入口左右分页。

## 安装

移除旧 FanqieX/FanqieAdBlock 动态库后注入本版完整 dylib，再重新签名安装。同一 App 只保留一份插件。安装后在设置页和新导出的日志中核对 `1.9.1beta17`。
