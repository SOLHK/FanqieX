# FanqieX 1.8R8 测试版

基于 1.8R7，面向番茄小说 7.4.3（7.4.3.33）。

- 「我的」与其他底栏入口共用滑移、膨胀和回弹。修改玻璃外观后再次进入「我的」时，将列表对齐顶部。
- 智能朗读的收起和更多使用圆形裁切。根据原著入口的位置调整顶部按钮，给更多与原著入口留出间距。
- 短剧加载时保留评论图标。计数可用后直接显示数字，加载阶段省略图标下方的「评论」占位文案。
- 短剧评论／剧评与阅读段评各用一块 UIKit 液态玻璃覆盖弹层。底部输入栏独立使用一条玻璃，保留输入、图片、表情和原有手势。
- 短剧分享选项面板使用整块系统玻璃，保留拖拽和各分享渠道。
- 「插件设置 → 短剧 → 右侧互动按钮」有收藏、评论、点赞和分享四个独立开关，默认开启。

用原有插件管理器替换 `FanqieX-1.8R8.dylib`，退出番茄小说进程后重开。
