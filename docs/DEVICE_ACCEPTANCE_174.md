# FanqieX 1.7.4 设备观察点

本文件是待执行的真机验收清单，不是通过记录。当前环境没有 iPhone、注入工具或
UIKit 渲染器，因此以下项目均未标记为通过。

## 阅读页

1. 打开任意章节，呼出底部工具栏；确认本章讨论、礼物、听、进度条、目录、夜间、设置、改编剧场都有玻璃，文字和图标位于玻璃之上。
2. 拖动进度条、长按、点击目录/夜间/设置/改编剧场；确认触摸区域、滑块拖动和原事件不变。
3. 反复退出/进入阅读页，切换横竖屏和明暗模式；确认没有白色矩形、文字模糊、错位或叠加。
4. 在设置页关闭玻璃，返回阅读页；确认材质消失且宿主背景/裁剪恢复。重新打开后恢复玻璃。

## 书架

1. 切换全部/阅读/听书/星标；确认选中态、滑动切换动画和分类筛选保持。
2. 反复切换 Tab 和滚动；确认四个入口无白色底板、文字不重叠。

## 个人页

1. 检查搜索栏、我的订单、浏览历史、我的消息、创作中心、我的预约。
2. 检查“羊了个羊：星球”卡片不再出现，且其上方/下方内容没有空白洞。
3. 检查其他快捷入口、推荐内容、滚动和跳转均存在。
4. 浅色/深色模式各检查一次。

## 底栏开关

1. 进入 FanqieX 设置页，确认“底栏显示：短句 / 商城”两个开关默认开启。
2. 分别关闭，确认对应 Tab 立即消失且其余 Tab 仍可点击；重新开启后恢复。
3. 关闭当前选中的 Tab，确认宿主自动切到可用 Tab，不崩溃、不留下空白。

## 构建/注入边界

- 仅在 `test` 分支验证；不得合并到 `main`。
- 若设备无法注入，记录为“未执行”，不能用模拟器或模型结果替代。
