# FanqieX 1.8R10 测试版

- 小说段评在阅读器的弹层内容区铺设玻璃，并在主题更新和容器布局时同步底色。
- 短剧评论去除展开回复的白条，调整浅色玻璃的文字对比。收起时缩短发评条，展开键盘时给输入框、操作行和表情区域使用统一的玻璃面板。
- 智能朗读顶部返回与更多按钮采用 38 × 38 pt 正圆，半径 19 pt，曲率约 0.05263 pt⁻¹。原著箭头玻璃按钮直径 28 pt，半径 14 pt。
- 搜索开关位于「插件设置 → 短剧 → 顶部分类 → 显示短剧右上角搜索按钮」，沿用已保存的状态，与分类开关独立。

用 1.8R10 替换旧 Dylib 后彻底退出番茄并重开。
