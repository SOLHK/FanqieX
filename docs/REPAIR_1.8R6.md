# FanqieX 1.8R6

基于 1.8R5，面向番茄小说 7.4.3（7.4.3.33）。

- 短剧外层信息流在漫剧与推荐切换重排时，根据可见进度轨道为「观看完整漫剧」保留至少 12 pt 的间距。拖动区域和轨道位置保留宿主行为。
- 智能朗读的上一章、播放或暂停、下一章与其他控件共用半透明深色液态玻璃。模糊封面使用覆盖整页背景的约束，滚动容器及其内容底色透出同一背景，处理音色与边听边读下方的分界。
- 「插件设置 → 外观 → 短剧右侧互动区 → 短剧空心图标大小」可在 26–42 pt 之间独立调节，默认 36 pt。收藏成功时星形显示黄色，取消后恢复白色。

在原有插件管理器中替换 `FanqieX-1.8R6.dylib`，退出番茄小说进程后重开。
