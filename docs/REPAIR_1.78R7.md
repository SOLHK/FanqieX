# FanqieX 1.78R7 测试版

基于 1.78R6，修复短剧自动收缩并调整液态玻璃控件的比例。

- 短剧翻到下一条后，底栏收缩为右侧的当前入口。点击收缩按钮展开，反向滑动继续保持收缩。
- 在底栏外观设置中独立控制短剧顶部分类、搜索按钮和作者声明的显示，关闭后隐藏，重新开启后恢复。
- 纯图标底栏使用清透玻璃，深色页面选中项加深，未选中图标降低亮度。图标使用较细字重，并继续采用已保存的尺寸。
- 调整阅读工具栏和个人页快捷入口的玻璃、图标及文字比例，保留原有触摸区域。

使用 `FanqieX-1.78R7.dylib` 替换旧插件，重新注入和签名安装。设置页或诊断日志应显示 1.78R7。

安装后检查连续切换短剧、点击收缩入口展开、三个显示开关、明暗页面切换，以及阅读工具按钮和个人页快捷入口。构建及自动回归结果记录在包内 `VERIFICATION.json`，真实 iPhone 的玻璃合成、动画和触控效果仍需设备复测。
