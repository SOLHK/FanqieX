# FanqieX 1.8R3

基于 1.8R2 的测试修复，针对番茄小说 7.4.3（7.4.3.33）上的五张截图反馈。

- **书架**。顶部和吸顶筛选区恢复宿主背景与刷新布局。分类、搜索和筛选按钮保留各自的液态玻璃。
- **底栏**。点击的玻璃选中态先滑移并膨胀，随后弹性回到原尺寸。过渡层按胶囊边缘裁切，并移除矩形填色。
- **段评**。用带小尾巴的对话气泡轮廓裁切整块玻璃，评论数居中。
- **智能朗读**。返回符号以实际玻璃圆心定位。移除固定控制区叠加的原生渐变，并将音色和边听边读卡片的玻璃限制在各自圆角内。

在原有插件管理器中替换为 `FanqieX-1.8R3.dylib`，退出番茄小说进程后重开。ZIP 内附验证记录。

段评遮罩直接应用于玻璃效果视图。底栏过渡保持玻璃效果视图的完整不透明度，避免半透明合成影响折射。参见 [Apple 的 UIVisualEffectView 文档](https://developer.apple.com/documentation/uikit/uivisualeffectview)。
