# FanqieX 1.78R13 测试版

面向番茄小说 7.4.3（7.4.3.33）。请先移除旧的 FanqieX 或 FanqieAdBlock 动态库，再注入测试包内的 ARM64 动态库并重新签名。

- 设置页按场景分组，左上角进入「外观」，右上角搜索设置。搜索支持连续关键字、按顺序出现的字符和多词组合。
- 「短剧滚动自动收缩」在翻到下一条并停稳后收起底栏。开启「默认清屏播放」和「纯净清屏」后，清屏会隐藏按钮、进度条、全集入口和底栏。沿用原生清屏退出手势。
- 「外观」里的短剧右侧互动按钮大小同步调整收藏、评论、点赞和分享的图标及底板。阅读页的听书浮条改用系统玻璃。「我的」快捷入口采用胶囊形，可在「外观」中只保留图标。
- 「诊断与测试」位于设置页底部。「开启诊断」默认关闭，开启即记录完整诊断。可导出此前保存的诊断。
- 在「设置 → 诊断与测试」打开「听书奖励本地测试」，点「模拟立即领取」便会立即显示模拟成功。该测试不发送正式请求、不发放实际奖励，也不会改变正式账号余额或领取条件。

本地测试包使用 Windows LLVM 构建。UIKit 视觉、触控、动态清屏以及重签名后的加载需要 iPhone 真机验证。
