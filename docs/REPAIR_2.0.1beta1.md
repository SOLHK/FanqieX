# FanqieX 2.0.1beta1

- 开启「查看全集与进度条跟随底栏长度」后，Dock 尺寸变化会触发当前短剧页布局。Dock 自动收起时，合集入口和进度条沿用展开宽度。
- 底栏选择延后到 UIKit 回调退出后，再由番茄小说处理切页。短剧控件由 UIKit 在后续布局中更新，减少切页中同步重排。
- 顶部分类根据宿主分页更新高亮。隐藏分类后，横滑按可见分类顺序切换。
- 「短剧 → 页面内容」新增隐藏「全屏观看」按钮的开关，默认关闭。开启后，原位置仍可点按进入全屏。
- 设置备份继续使用 `.fqcfg`，导入通过设置页使用的偏好存储写入并回读。合并和替换模式均保留番茄小说自己的设置。

将 `FanqieX-2.0.1beta1.dylib` 替换到原来的注入位置，重新签名安装。打开 FanqieX 设置，核对版本 `2.0.1beta1`，然后按 [真机验收说明](../TESTING.md#201beta1-真机验收) 检查对应操作。
