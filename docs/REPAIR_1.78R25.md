# FanqieX 1.78R25

适用番茄小说 7.4.3，内部版本 7.4.3.33。本轮提交到 test 分支。

## 本轮修复

- 分级设置使用原设置页的 UITableView。分类在显示前同步生成，首次打开即建立数据源，消除嵌套列表和子控制器显示回调造成的空白。
- 首页和子菜单的搜索、导出及页面跳转使用当前可见控制器。
- 原著入口在宿主 modelDidUpdate 重新设色后同步更新材质，消除圆角矩形背景在玻璃胶囊外露出的四角。关闭插件玻璃后恢复宿主背景。

## 本轮包含的本地测试功能

- 修正短剧底栏自动收缩使用的页面识别。收缩位置支持左、中、右，关闭自动收缩时隐藏位置入口。
- 原著、合集和横屏互动入口的玻璃布局优化。合集入口与展开底栏等宽。
- 阅读、书架、我的页面净化，每项独立开关，新净化项目默认保留入口。章末内容在重新进入书籍后应用。
- 前台通知提醒与 App 运行期间的角标控制。后台通知由 iOS 系统设置管理。
- 双击正文切换自动阅读，以及独立的本地广告时长限制选项，默认关闭。
- 默认启动页及书城顶部分类管理，书城分类重启后应用。
- FanqieX 专用 .fqcfg 设置导出、合并恢复、覆盖恢复和恢复默认值。导入检查格式、长度、完整压缩流及 CRC32，跳过未知项。
- 视频原文件保存支持常见容器，格式转换使用系统支持的 MP4、MOV、M4V。支持的 HLS 点播可保存为 MOVPKG。视频来源和系统支持决定实际可导出能力。
- 按功能分级的设置和覆盖子菜单的搜索。

新增模块独立实现，参考材料用于确认宿主接口和操作流程。

## 构建与验证

GitHub Actions 为同一提交构建 Xcode 产物并验证候选字节、加载结构、ARM64 回归和打包一致性。
工作站可完成编译及离线检查，真实 UIKit 渲染、系统文件选择与视频导出需在 iPhone 上复测。

重点检查首次打开设置、搜索并进入子菜单、关闭玻璃恢复原著背景，以及切换视频后原著胶囊四角是否保持平滑。

## 安装

使用新的单个 FanqieX-1.78R25.dylib 替换旧动态库后重新注入并签名，同一宿主加载一份插件。
