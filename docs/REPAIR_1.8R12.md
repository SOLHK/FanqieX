# FanqieX 1.8R12 修复说明

基于 `1.8R11` (`dc25e0b`) 修复以下问题：

- 书架冷启动加载完成前不再短暂闪现「书架暂无书籍」空态卡片（本地书籍加载完成后若确实为空仍正常显示）。
- 短剧评论区与读书评论区液态玻璃面板改为左右 0pt 贴边全覆盖并消除底部圆角缝隙，统一评论区与发评论条液态玻璃底色并适度提高通透度。
- 清理底部发评论栏内残留的旧版圆形按钮玻璃层，修复图片/表情小按钮显示异常。
- 清除发评论展开编辑卡片外层不透明白底遮罩，使其在键盘上方以纯悬浮液态玻璃呈现。
- 短剧「剧评」标签页（列表、评分卡片、评论行）全面适配液态玻璃，并将底部「写剧评」按钮改造为原生交互式液态玻璃胶囊按钮。
- 读书评论区清除外层白底包装遮罩与导航栏不透明底色，露出后方正文折射效果。
- 短剧点进「查看全集」（单剧详情页）同步移除底部遮罩并将竖屏画面自然延伸至选集栏下方。
