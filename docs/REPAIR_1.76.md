# FanqieX 1.76

- 短剧主底栏使用单层悬浮液态玻璃，清除外层遮罩，让视频能够透过底栏。视频区域延伸到底栏后方，控制区保留独立高度，全集和合集入口不会与底栏重叠。
- 底栏读取当前页面提供的背景色，自动切换深浅玻璃、文字和选中态。系统为浅色时，短剧等黑色页面使用局部深色外观；切回浅色页面时恢复对应材质。
- 短剧右侧互动、观看完整漫剧及合集入口保持液态玻璃，覆盖复用与异步显示场景。
- 全屏播放保留原始宽高比，不拉伸、不裁掉上下内容。剩余屏幕使用播放器原生动态背景，连续切换视频时重新应用全屏填充设置。画质由原始视频源和播放器决定。
- 书架筛选按钮开关控制真实入口的显示状态。
- 阅读页使用黑色背景时，页内玻璃控件采用深色外观。阅读背景与应用主题可以独立，外部页面继续遵从设置中的夜间模式与跟随系统选项。

先移除旧的 FanqieX 或 FanqieAdBlock 动态库，再注入 `FanqieX-1.76.dylib` 并重新签名。同一个宿主只加载一份插件。
此动态库需要注入番茄小说宿主使用，不是独立安装的 App。

自动验证执行实际 ARM64 指令，并以明确的 UIKit、Foundation 和宿主接口模型验证布局、材质复用、主题隔离、入口开关、点击路由、Mach-O 结构及签名页哈希。
发布包由 Xcode 27.2 / iOS 27.2 SDK 构建，构建和验证记录可在同一提交的 GitHub Actions 中查询。
真实 iPhone 的最终合成、动态折射、触控、性能及 IPA 注入仍需设备验证。
