# FanqieX 1.9.6beta6 测试版

本版基于 1.9.6beta5，Mach-O 构建标识为 `0x15606`。

在「书架净化 → 收藏页」可以分别控制「全部」「短剧」「漫剧」「其他视频」标签、「编辑」按钮和「查看短剧浏览历史」卡片，六项均默认显示。

「我的」会在福利单元格首次布局时应用金币与福利卡片开关，覆盖宿主从缓存恢复卡片的路径。

使用现有 IPA 注入和重签名流程，将原有 FanqieX 动态库替换为 `FanqieX-1.9.6beta6.dylib`。同一个宿主只加载一份 FanqieX。

验证状态记录为 `device_tested: false`，待 iPhone 验证收藏页切换和各开关的显示效果。
