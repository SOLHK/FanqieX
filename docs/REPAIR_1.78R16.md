# FanqieX 1.78R16 测试版

适用番茄小说 7.4.3（内部版本 7.4.3.33）。按原有流程将旧插件替换为 `FanqieX-1.78R16.dylib`，再重签 iOS 应用。安装包内的单个动态库同时包含 FanqieX 和本地小说导出。

- 书架进入「历史」时加载综合历史。用户仍可在页面内切换原生分类。
- 「显示短剧顶部分类」主开关控制整行。首次进入短剧页加载分类后，FanqieX 设置的「短剧播放」会按实际名称显示各分类的独立开关。全部关闭时仍可播放当前内容。
- 设置页、诊断日志、动态库标识和构建产物统一显示 1.78R16。使用现有的安装方式和插件偏好。

复测历史入口首次进入、离开再进入及切换到短剧分类的行为，再检查短剧顶部分类的主开关与各入口。真机的 UI 和触控效果以设备验证为准。
