# FanqieX 1.78R36 测试版

适用番茄小说 7.4.3（7.4.3.33），仅推送到 test 分支。

## 布局修复
- 将短剧、漫剧及看剧进度轨道与「观看全集」入口的目标间距从 8 pt 提高到 12 pt。
- 在父布局、子布局、进度样式首次提交、播放/暂停及选集插入回调后重新计算，避免来回切换推荐/漫剧/看剧时使用旧几何。
- 位移只作用于唯一确认的剧集入口/信息组；保留原生 seek view、进度填充、手势及约束恢复。
- 详情页复用同一校正，避免全集/选集入口贴近底部播放区域。

## 新增设置
1. 关闭短剧进入自动播放
2. 关闭阅读评价邀请
3. 隐藏书摘小组件提醒
4. 隐藏内容小组件提醒（仅 widget_history）
5. 隐藏书城发帖按钮
6. 净化听读赚钱悬浮挂件
7. 短篇正文广告处理
8. 热启动广告专项拦截
9. 听书广告专项控制
10. 返回标题固定为章节名称

每项默认关闭，需在 FanqieX 设置中单独开启。广告专项不修改网络请求、账户计费或普通视频/音频播放链路。

## Hook 安全
- 新增 FQXHookInstaller：验证目标类、选择器和精确 ABI。
- 继承方法先在目标类/元类建立本地方法副本，再修改本地 IMP，不触碰父类。
- 保存原 IMP；同一类/选择器只允许安装一次；不匹配或安装失败就跳过。

## 验证边界
GitHub Actions 使用 Xcode 27.3/27.2 重新生成 AlignedGlass 汇编，构建 ARM64 核心与集成 Objective-C companion，并执行 Hook ownership、短剧间距和 Foundation smoke tests。CI 未通过前不发布安装包；UIKit 实际渲染、手势和真机注入仍需设备测试。
