# FanqieX 1.9.6beta7 测试版

本版基于 1.9.6beta6，Mach-O 构建标识为 `0x15607`。

- 在短剧详情页「原著」入口、宿主路由和进入阅读页的调用点前后同步写入诊断阶段，宿主继续执行原有跳转。
- 应用失去前台或进入后台时写入会话记录。进程结束后重开应用，可通过「诊断与其他 → 导出日志」查看上一次已落盘的记录与会话状态。系统未提供结束回调时，导出中的结束原因标为未知。

使用现有 IPA 注入和重签名流程，将原有 FanqieX 动态库替换为 `FanqieX-1.9.6beta7.dylib`。同一个宿主只加载一份 FanqieX。

验证状态记录为 `device_tested: false`。「原著」闪退原因仍待设备日志或 iOS 崩溃报告定位，真机保存和导出待复测。
