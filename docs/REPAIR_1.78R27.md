# FanqieX 1.78R27 本地测试版

适用番茄小说 7.4.3（7.4.3.33）。本次修正插件设置的真实呈现入口及短剧顶部选中样式，未推送 GitHub、未触发 CI。

## 设置首页

R26 通过替换旧设置表格的数据源挂接新菜单，仍呈现旧控制器。之前的离线设置测试没有执行新菜单安装，不能证明设备上能看到新菜单。R27 改为在原插件设置入口创建导航之前，将根控制器直接换成独立的 `FQXSettingsMenu`。旧控制器只保留原有控件和动作，不显示它的表格。

首页正常状态只显示大分类：页面与导航、阅读、短剧、书架净化、我的页面净化、通知管理、导出与备份、外观、广告与福利、诊断与其他。功能开关放入对应的二、三级页面；搜索时才跨分类显示具体功能。

| 功能 | 插件设置内的入口 |
| --- | --- |
| 双击正文切换自动阅读、本地广告时长选项 | 阅读 → 自动阅读 |
| 作者的话、讨论、圈子、论坛、礼物、最新章三个按钮、开启评论 | 阅读 → 阅读页面净化 → 章末内容 |
| 去赚更多、听书悬浮按钮、改编剧场 | 阅读 → 阅读页面净化 → 正文与底栏 |
| 推荐横幅、今日听读时长 | 书架净化 → 顶部与统计 |
| 本地书导入、漫剧推荐 | 书架净化 → 推荐与导入 |
| 推荐和福利卡片 | 我的页面净化 → 内容卡片 |
| 发帖按钮 | 我的页面净化 → 悬浮入口 |
| 前台通知提醒、App 运行期间角标 | 通知管理 |
| 当前视频导出 | 导出与备份 → 导出当前视频 |

净化项开启“隐藏”才移除对应内容，升级保留已有配置。自动阅读相关选项默认关闭。章末净化重新进入书籍后应用；通知管理不伪造系统权限，后台系统提醒由 iOS 通知设置控制。视频导出能力沿用 R26：原文件保存，系统支持的 MP4/MOV/M4V 转换及可支持的 HLS 点播离线包。

## 顶部选中样式

短剧顶部选中块与底栏使用同一系统填充色、胶囊圆角和 4 pt 内边距，覆盖完整分类区域，移除原硬编码黑色小块。页面明暗适配复用底栏的宿主背景判断。保留当前页面模型决定选中状态及原生分类点击。

## 实际验证

- ARM64 iOS 编译及单库链接通过。
- 新测试执行完整插件设置入口和核心桥接，确认传给导航的根控制器为新菜单，并检查引用交接、寄存器和栈。旧 R26 在同一根页断言失败。
- 顶部分类专项通过：系统填充刷新、完整选中区域、内边距、隐藏相邻项、原生索引及当前页状态同步。
- 合并库内实际存在菜单 factory、净化开关来源、自动阅读模块及视频导出入口；加载结构、页哈希和合并启动检查通过。

入口测试把独立 Objective-C 菜单作为明确的运行时边界，并未执行真实 UIKit 渲染。工作站没有连接 iPhone；设置页面最终显示、各开关行为及触摸观感仍待真机验证，不能把上述检查当作设备验收。

## 安装

替换旧插件，注入 ZIP 内唯一的 `FanqieX-1.78R27.dylib` 后重新签名。打开插件设置应先看到分类列表，具体开关位于子页面。包内 `VERIFICATION.json` 和 `verification/` 保存本次实际检查结果。
