# FanqieX 1.78R26

适用番茄小说 7.4.3（7.4.3.33），基于 R25 的本地测试包。本次未推送 GitHub、未触发 CI。

## 本次修复

- 顶部分类：恢复宿主 cell 宽度和间距，胶囊覆盖完整首末项；移除只扩大 cell 而未同步宿主内容模型的布局改动。点击仍走原分类索引。
- 选中底片：从宿主 `currentTabModel` 确定当前页，布局和分类完成回调后同步，避免读取另一份陈旧的标题控件索引。
- 底栏收缩：原尺寸文字淡出，玻璃使用临界阻尼弹簧收拢；连续点击时从当前显示位置衔接。支持系统“减少动态效果”。动画快照不接收触摸。
- 菜单：净化开关统一为“隐藏……”；新设置默认保留内容，已有显示键值与原刷新回调继续使用。按用途划分二、三级菜单。
- 搜索：预建全局索引，支持繁简与同义词，优先标题匹配；关闭自动收缩时仍能搜到收缩位置并显示启用条件。
- 视频：导出时重新取得同一集延迟就绪或切换清晰度后的地址，识别无扩展名 HLS；用宿主视频标识区分输出文件。

R25 已包含下述功能源码和安装入口。本轮改善它们的菜单可发现性和操作语义，没有复制 FanqieFN 实现。

## 功能入口

| 入口 | 内容 |
| --- | --- |
| 阅读 → 阅读页面净化 → 章末内容 | 隐藏作者的话、讨论、圈子、论坛、礼物、最新章节三个按钮、开启评论 |
| 阅读 → 阅读页面净化 → 正文与底栏 | 隐藏去赚更多、听书悬浮按钮、改编剧场 |
| 阅读 → 自动阅读 | 双击正文切换、独立的本地广告时长限制开关 |
| 书架净化 → 顶部与统计 | 推荐横幅、今日听读时长 |
| 书架净化 → 推荐与导入 | 本地书导入、漫剧推荐 |
| 我的页面净化 → 内容卡片 | 推荐、金币与福利卡片 |
| 我的页面净化 → 悬浮入口 | 发帖按钮 |
| 通知管理 | 前台通知提醒、App 运行期间的角标 |
| 导出与备份 → 导出当前视频 | 原文件、系统格式转换、HLS 离线包 |

开启“隐藏”才会移除对应入口。章末开关重新进入书籍后应用。双击自动阅读和本地广告时长选项默认关闭；后者只控制已匹配的本地自动阅读限制，不改变网络奖励结算。通知管理保留真实系统授权状态，后台系统提醒继续由 iOS 设置管理。

## 视频范围

先播放目标视频，再打开导出入口。原文件保存识别 MP4、MOV、M4V、3GP、3G2、TS、M2TS、MPEG、AVI、MKV、WebM、FLV、F4V。转换只列出当前设备支持的 MP4、MOV、M4V；可支持的 HLS 点播保存为 MOVPKG 离线包，不等同于单个 MP4。加密、直播、分离音视频和系统不支持的来源会提示原因，不能承诺任意格式转码。

## 验证与安装

使用本轮重新编译的单个 `FanqieX-1.78R26.dylib` 替换旧动态库，再按原流程注入和签名。同一宿主只加载一份插件。

ARM64 iOS 编译、加载结构/页哈希、合并启动路径及本轮顶部分类回归已检查。测试报告区分核心 ARM64 执行、原生 C 容器测试与 UIKit 建模边界，最终结果随包记录在 `VERIFICATION.json`。

工作站没有连接 iPhone；实际菜单、全套净化效果、双击自动阅读、系统通知、动画观感和视频分享仍待真机验证。重点切换推荐/漫剧/看剧，连续收缩与点击展开，搜索“隐藏作者的话”“改编剧场”“自动翻页”“视频导出”并进入对应功能。
