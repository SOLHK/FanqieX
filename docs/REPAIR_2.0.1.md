# FanqieX 2.0.1 正式版更新说明

## 2.0.1 正式版汇总功能（整合全部 2.0.1beta1–2.0.1beta12 与正式版优化）

1. **动态收缩底栏与 120Hz 全场景流畅交互**
   - 「页面与导航 → 底栏入口」合并为「动态收缩底栏」四档互斥模式：**关闭**、**原有收缩模式**（单圆按钮及左右位置）、**TikTok 交互**（多图标等比缩放居中，81% 宽度 / 80% 高度 / 91% 图标）与 **Siri AI 交互**（连续聚拢压成纯白短线，支持「Siri AI 收缩后隐藏短线」延迟淡出与下拉连续恢复）。
   - 全面覆盖**短剧、书城、书架、我的**四大主页面，同步联动右侧独立圆形底栏模块与收缩态点击穿透；采用三阶 $C^2$ 流体弹簧与原位文字缩放淡出（杜绝图标与文字重叠），并修复冷启动或长时间未滑动后首滑无响应的问题。
   - **2.0.1 正式版流畅度专项优化**：
     - 锁住 ProMotion 80–120Hz 高刷区间并复用常驻 `CADisplayLink`（消除每次滑动后的销毁/重建延迟），延长慢拖手指按住期间的保活窗口并修复恢复首帧 `lastFrame` 跳变，消除慢速拖动与快速轻拂时的偶发掉帧与抖动；
     - 将底栏折叠模式、显示模式、图标尺寸与模糊度纳入无锁热点偏好缓存，120Hz 手势与触摸事件零 `NSUserDefaults` / 互斥锁开销；
     - 滑动与弹簧动画期间短路无关宿主 `syncWithBar:` 重排，`FQXBackdropBlurView` 缓存已应用硬件模糊参数避免重复写 `CABackdropLayer` 滤镜，弱引用缓存原生选中透镜、非听书页面零全应用 VC 树扫描，短剧滚动每帧仅刷新一次视频背景。

2. **底栏与短剧配色体系升级**
   - 顶部与短剧按钮、Dock 栏新增 **「粉雾玻璃」**（带透明粉雾底色与同色系粉雾渐变选中的真实液态玻璃）、**「柔性粉雾」** 渐变选中色与 **「视频同款底色（非玻璃）」** 哑光瓷灰底色。
   - 彻底拆分独立的 **「Dock 选中色」**（`FanqieX.DockSelectionTintStyle.1`）与 **「短剧顶部按钮选中色」**（`FanqieX.DramaTopSelectionTintStyle.1`），升级 iOS 26/27 原生 `UITabBar` 选中胶囊定位与兜底跟随机制（兼容 `_UILiquidLensView`），修复深色液态玻璃底栏下选中胶囊发黑问题。
   - 移除短剧右侧点赞、收藏、评论、分享四个互动按钮的圆形玻璃或哑光底色遮罩，保持干净悬浮图标。

3. **听书全系二级半屏弹窗玻璃化**
   - 为听书页面全部二级半屏弹窗（语速、加入书架/已加书架、选择章节/下载、章评、更多、简介/播放目录、定时关闭与音色设置）统一提供 **「听书弹窗材质」**（液态玻璃/模糊玻璃/高斯模糊/原版默认）与 0%–100% **「听书弹窗模糊程度」** 自定义调节，并保持听书主界面原有液态玻璃不重复叠加第二层卡片。

4. **短剧播放、设置分类整理与体验修复**
   - 重整设置分类，将「短剧顶部与按钮底色」、「短剧顶部按钮选中色」、「顶部按钮大小」、「短剧顶部按钮模糊程度」、「液态玻璃深色底色」与「长按播放选项面板材质/模糊程度」集中置顶于 **「短剧」** 一级页面；「外观 → 玻璃与尺寸」聚焦 Dock 材质、Dock 选中色、Dock 模糊度与底栏尺寸。
   - 短剧查看全集入口与进度条自动跟随 Dock 长度；新增「隐藏全屏观看按钮」（保留原位点击进入全屏）与「隐藏短剧标题入口」。
   - 修复短剧顶部分类轻点未切页、首次进入书架历史内容空白、底栏切换重复布局卡顿及设置备份导入后未恢复的问题；设置首页版本弹窗完整展示 2.0.1 正式版全部更新并支持「查看历代更新」。
