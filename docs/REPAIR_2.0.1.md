# FanqieX 2.0.1 更新说明

## 本版更新

1. **彻底拆分「Dock 选中色」与「短剧顶部按钮选中色」**
   - 原共用选项拆分为独立的 `Dock 选中色`（`FanqieX.DockSelectionTintStyle.1`）与 `短剧顶部按钮选中色`（`FanqieX.DramaTopSelectionTintStyle.1`），均支持 `默认 / 柔性粉雾 / 粉雾玻璃` 独立搭配，并兼容旧配置平滑迁移。
   - 升级 iOS 26/27 原生 `UITabBar` 选中胶囊定位与兜底跟随机制（兼容 `_UILiquidLensView` 及隐藏镜头层级），解决深色液态玻璃底栏下选中胶囊发黑、与黑色图标重叠不可见的问题。

2. **移除短剧右侧互动按钮的玻璃遮罩**
   - 收藏、评论、点赞、分享四个右侧互动按钮不再附加圆形玻璃或哑光底盘，恢复干净悬浮图标外观；顶部分类胶囊、搜索按钮及全集/原著/弹幕/全屏按钮继续支持「默认液态玻璃 / 视频同款底色（非玻璃） / 粉雾玻璃」。

3. **优化设置分类：短剧外观与顶栏设置集中置于「短剧」一级页面**
   - 将「短剧顶部与按钮底色」、「短剧顶部按钮选中色」、「顶部按钮大小」、「短剧顶部按钮模糊程度」、「液态玻璃深色底色」与「长按播放选项面板材质/模糊程度」统一前置到「短剧」一级页面，无需层层翻找。
   - 「外观 → 玻璃与尺寸」聚焦 Dock 材质、Dock 选中色、Dock 模糊度与底栏尺寸，职责清晰。
