# FanqieX 1.9.7beta7 测试版

本版基于 1.9.7beta6，Mach-O 构建标识为 `0x15707`。

- 在短剧的推荐、最近、收藏之间连续左右滑动，检查拖动结束时是否还会误进剧集。点按剧集和上下滚动仍应可用。
- 隐藏书架类别后，从两侧横滑验证可见页面顺序。历史页的短篇、漫画、话题各自开关，关闭一项后检查另外两项和历史列表。
- 在短剧中长按打开播放选项面板，再从分享入口打开分享面板。分别切换模糊玻璃和高斯模糊，检查背景材质与强度。

沿用现有 IPA 注入及重签名流程，将旧库替换为 `FanqieX-1.9.7beta7.dylib`。同一个宿主只加载一份 FanqieX。

构建报告中的 `device_tested: false` 表示未进行真机验证。
