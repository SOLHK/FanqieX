# FanqieX 1.8R5

基于 1.8R4，面向番茄小说 7.4.3（7.4.3.33）。

- 短剧右侧互动区设为 40 或其他自定义尺寸时，收藏和点赞按原始图案的点尺寸缩放。首屏布局与宿主换图走相同的尺寸计算，切回 50 时恢复原生图案。圆底、数字和点击区域各自保留原有布局。
- 短剧空心样式采用圆角星形、圆弧气泡、柔化心形与纸飞机，沿用已有开关，并随互动按钮大小设置缩放。
- 阅读器段评交回番茄小说原生渲染，保留宿主评论数和点击行为。
- 智能朗读使用 UIKit Regular 液态玻璃，控件内部增加暗色衬底并提高标签亮度，降低不同封面颜色对可读性的影响。关闭朗读主内容和嵌套滚动容器的底部边缘效果，并清理音色、跟读卡片及其容器的投影。
- 书架五项快速筛选均匀留出间距，滚动区域在独立「筛选」按钮前留出 8 pt。

在原有插件管理器中替换 `FanqieX-1.8R5.dylib`，退出番茄小说进程后重开。ZIP 内附验证记录。
