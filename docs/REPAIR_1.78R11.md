# FanqieX 1.78R11 测试版

面向番茄小说 7.4.3（7.4.3.33）。

- 书架顶部和筛选胶囊收紧并留出间距。切换选项时固定胶囊、字号和文字中心，保留选中颜色；筛选玻璃放在原行高度内。
- 竖屏短剧的「全屏观看」在首次布局和复用后都应用液态玻璃。收藏、评论、点赞、分享共用一个玻璃直径滑块（36–54 pt，默认 50 pt），保留触控区域、图标和数字位置。
- **FanqieX → 底栏外观与尺寸 → 短剧页面** 新增「默认清屏播放」「暂停时显示界面」「默认最高画质」三个开关，默认关闭。暂停显示会在继续播放时恢复清屏；会尊重当前视频的手动清屏退出及原生画质选择。最高画质取当前播放源可用的最高档。

测试包由 GitHub Actions 使用 Xcode 27.3 和 iOS 27.3 SDK 构建；构建版本和校验记录随包提供。
安装前移除已注入的旧 FanqieX / FanqieAdBlock，再注入本包并重新签名。清屏、暂停恢复、最高画质和实际玻璃观感需要在 iPhone 上复测。
