# FanqieX 1.78R12 测试版

面向番茄小说 7.4.3（7.4.3.33）。

- 书架顶部控件与默认底栏使用同一组左右边距，更多、编辑和筛选右缘对齐，更多图案在圆内居中。
- 阅读页返回箭头按图案的可见范围居中。
- 短剧主页面清屏时隐藏右下角退出按钮。暂停时显示界面仍由插件开关控制。
- 横屏播放器拉开返回与标题、弹幕开关与输入框的距离。倍速、画质和选集按钮留出文字边距并统一间隔。辅助圆按钮统一尺寸，中央播放保留主按钮尺寸。

测试包使用 Xcode 27.3 和 iOS 27.3 SDK 构建。注入前替换旧 FanqieX 或 FanqieAdBlock，并重新签名。按钮的实际观感和触控需在 iPhone 上复测。
