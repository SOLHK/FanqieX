# FanqieX 1.78R9 测试版

基于 test 分支 1.78R8（b289158），处理本轮 12 张截图及三份诊断中的反馈。

| 截图 | 本轮改动 |
| --- | --- |
| 1 | 我的页静止时顶部与页面底色衔接，滚动时恢复模糊；快捷入口统一图标、字号和玻璃尺寸；增加继续追剧／追漫显示开关。 |
| 2 | 书架短标题、筛选、编辑与时长条统一玻璃高度；长标题保留文字需要的宽度。 |
| 3 | 横屏返回、分享、更多、播放、锁屏、亮度、音量、完整漫剧、点赞／评论／收藏、弹幕、倍速、清晰度与选集控件增加液态玻璃，保留原按钮操作。 |
| 4、5 | 增加「去赚更多」和「根据小说兴趣推荐」的独立显示开关。 |
| 6、7 | 底栏文字槽至少 64 pt、图标槽至少 56 pt，较短设置自动保留点击空间。 |
| 8 | 增加侧栏常玩游戏显示开关。 |
| 9 | 自动收缩改为监听实际短剧 FQV 列表的翻页结束事件；点收缩按钮展开。 |
| 10、11 | 恢复书架原生筛选吸顶，并将浮动筛选放到顶部栏下方。 |
| 12 | 增加书架漫剧分组显示开关，保留收藏及原始数据。 |

新增开关位于 **FanqieX → 底栏外观与尺寸**，下滑到「短剧页面」和「其他页面」。默认开启；关闭即隐藏对应入口。

## 安装与实机复测

移除旧 FanqieX / FanqieAdBlock 动态库，再注入本包并重新签名；同一 App 只加载一份。重启后确认插件版本为 **1.78R9**。

重点复测：底栏轻点与连续切页；短剧滑到下一条后收缩及点开；书架滚动时筛选持续可见；开关关闭再开启后的恢复；横屏每个控件的点击、显示／隐藏与玻璃观感。

本次交付使用 Windows 上的 Clang 18 ARM64 Objective-C 编译与 LLVM 汇编构建。验证执行候选的实际 ARM64 指令，UIKit / Foundation 是显式边界模型；另检查 Mach-O、版本、签名页哈希和原始段保护。

**本轮没有执行 Xcode 构建、iPhone 安装、真实 UIKit 渲染或触感测试。** 各项实际验证及构建哈希见随包 `VERIFICATION.json`。代码已处理上述反馈，实机效果仍待确认。
