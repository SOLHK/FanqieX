# FanqieX 2.0 启动修复

在番茄小说 7.4.5（7.4.5.33）、iOS 27.3 Beta 上，三次启动均因创建首个场景超时，被系统以 `0x8BADF00D` 终止。三份日志均显示主线程正在同步等待，插件后台清理旧偏好时停在通知投递的 `waitUntilFinished`。

2.0 的偏好观察者在通知发出线程上只安排一次异步检查，立即返回。主线程就绪后读取最新设置，只有相关开关变化才刷新挂件。连续写入偏好可以合并处理。

书架默认显示小说改编剧推荐卡。在「书架净化 → 推荐与导入」开启「隐藏小说改编剧推荐卡」，书架会重新布局，收起「你看过的小说上架改编剧了」卡片。关闭隐藏后，书架恢复显示当前仍可推荐的卡片。

用 `FanqieX-2.0.dylib` 替换原有 FanqieX 动态库，重新签名并安装。完全退出番茄小说后重新打开，确认能进入首页并打开插件设置。设置首页和导出诊断日志应显示版本 `2.0`。

产物的 Mach-O 安装名为 `@rpath/FanqieX-2.0.dylib`，版本字段为 `0x20000`。
