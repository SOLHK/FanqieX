# FanqieX 2.0.1beta10

1. 听书页右上角 `⋮` 与底部「更多」按钮弹出的半屏弹窗新增独立可自定义调节的「听书更多面板模糊程度」（0%–100%，位于设置 → 阅读 → 智能朗读 与 外观 → 玻璃效果），实时生效并纳入设置备份。
2. 针对「稍微提一点就放手 / 稍微拉一点就放手」场景，为 TikTok 交互与 Siri AI 交互引入三阶解析 $C^2$ 峰值连续流体弹簧释放模型：初始速度连续、初始加速度为零，彻底消除首帧跃变、停顿甩动与僵硬回弹，且单次弹性回落无二次余震。
3. 将 TikTok 交互与 Siri AI 交互的原生纵向手势旁听扩展至「书城」「短剧」「书架」「我的」四大主页面，自动过滤横向分类分页器、轮播横条、侧栏及二级页面，切换底部 Tab 时平滑弹性恢复。

使用 `FanqieX-2.0.1beta10.dylib` 替换旧版 FanqieX 动态库，重新签名并安装。在 FanqieX 设置首页可核对版本号。
