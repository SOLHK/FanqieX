# FanqieX 1.6.1 设备观察点

用原有 IPA 注入及重签名流程替换旧插件，一个宿主进程只加载一份 FanqieAdBlock。
完全退出后重新打开，确认设置/导出的版本为 1.6.1。

## 阅读页

- 返回、下载、评论、搜索、更多恢复番茄原来的图标、尺寸与背景；插件不再画小玻璃圈。
- 各按钮原来的点击动作正常，顶部文字、图标和触点没有额外位移。
- 阅读页底部目录/夜间/设置/改编剧场与“听”仍可使用。
- 日志的 `reader_layout` 中 `readerTopOriginalControls=1`。

## 主底栏

- 四个入口、标题和页面对应关系正确，尤其从“书架”进入其他页再返回。
- 在明亮封面、深色封面和正文都位于底栏下方时，四个标题与选中项仍清楚。
- 在当前选中项内拖动，以及从未选中项开始拖动，观察选择器是否连续跟手。
- 松手只完成一次正确切页；拖到其他项后取消不应留下错误选中状态。
- 连续切页、后台返回、横竖屏变化后没有重复控件、短暂白遮罩或文字消失。
- 系统降低透明度/增强对比度开启时优先保证文字清晰，不要求系统仍提供同样的折射。

## 判断实际走哪条路径

导出日志查看 `bottomBarRenderer`：

| 值 | 含义 |
| --- | --- |
| `UISegmentedControl` | 由系统原生选择器负责交互和外观 |
| `RegularGlassPlainSelectionFallback` | 兼容回退：单 Regular 底材＋普通灰色选择填充 |

系统选择器本身不是 `UIVisualEffectView`；它的 `effectClass=null` 不表示内部
系统材质失效，不能套用旧版本“小镜片没有 effect”的判断。
记录 `hostSDKName` 与 `hostDesignRequiresCompatibility` 有助于解释外观差异，
不能凭这两个字段证明 GPU 已显示折射。

如实际效果仍有问题，保留一次从冷启动、切页到拖动的短录屏和同一时段日志；不要
只凭静态截图判断拖动帧。当前离线/构建验证不替代这一项设备观察。
