# FanqieX 1.78R14 测试版

适用番茄小说 7.4.3（内部版本 7.4.3.33）。请移除旧的 FanqieX 或 FanqieAdBlock 动态库，注入本包中的 ARM64 动态库并重新签名。

- 底栏可直接点按标签，也可沿底栏横拖。拖动时透明液态玻璃选中胶囊跟随手指，松手时切换到所在标签。
- 短剧「观看完整短剧」与进度条贴边时留出至少 8 pt。打开「暂停时显示界面」后，暂停会恢复底栏和进度条，继续播放时恢复清屏。
- 阅读页和书架的听书浮条使用系统液态玻璃。封面、播放或暂停、关闭和拖动沿用原交互。
- 「阅读与书架 → 截图后一键分享」默认开启。关闭后隐藏番茄小说自己的截图分享卡片，系统截图照常可用。
- 「诊断与测试 → 开启诊断」默认开启。升级时沿用已保存的诊断设置。
- 设置页按可见面板宽度调整卡片及搜索框，右侧开关保留统一边距。

本地 ARM64 构建、结构检查和本次改动相关的模拟回归已通过。UIKit 的实际触控、玻璃渲染和重签名后加载待 iPhone 验证。
