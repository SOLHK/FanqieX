# FanqieX 1.8R2

基于 1.8R1 的测试修复，面向番茄小说 7.4.3（7.4.3.33）。

- 底栏跨标签点按时，选中玻璃先用约 0.44 秒滑到目标位置，再用 0.16 秒完成交接。重复点按当前标签保留轻微回弹，滑动松手从手指最后的位置平稳收回。
- 智能朗读左上角的返回符号以圆形玻璃中心定位。插件设置的「阅读 → 智能朗读 → 朗读按钮仅显示图标」可隐藏语速、书架、下载、章评、更多、目录和定时的文字。开关默认关闭。
- 播放全集中的竖屏视频时，符合铺底条件的画面等比延伸到选集栏背后。选集、进度条和清屏入口继续使用原生控件。
- 书架、历史、收藏、圈子切换后，当前分页的原生搜索入口都有圆形玻璃。书架快速筛选与上方分类对齐，吸顶时由共享背景覆盖两行，关闭原生边缘渐变产生的色块。

在原有插件管理器里替换为 `FanqieX-1.8R2.dylib`，退出番茄小说进程后重开。ZIP 内附验证记录。
