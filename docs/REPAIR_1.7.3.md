# FanqieX 1.7.3 · test

本次修复右上角“分类”入口玻璃消失、搜索框四角残留，以及轮播书名溢出到下方导航的问题。

## 已确认的代码缺陷与修复

- 旧版本对首页搜索框调用通用 PrepareOwner，关闭 clipsToBounds。ARM64 边界回放中，搜索框外的下一条书名因此仍有可绘制区域；旧容器仍保留 6pt 小圆角。
- 新增只用于首页搜索框和右上角分类入口的 FQHHeader 路径。保留内容裁剪，并按当前尺寸同步容器半高圆角；玻璃本身继续使用系统 UIGlassEffect Regular 与 capsuleConfiguration。
- 恢复 SSBookStoreCategorySignView 的布局和主题 Hook。该类是右上角分类入口，不是下面的横向导航选项；不修改导航标签的 frame、字体、文字或点击行为。
- 宿主主题和搜索切换回调原样转发一次，已有材质复用；关闭玻璃时恢复宿主最新背景、裁剪和圆角，不覆盖宿主后续自主写入。
- 新增 headerLayout173 诊断，记录边界、裁剪、圆角及受限数量的子视图坐标，不记录书名或搜索内容。

## 验证边界

离线测试执行插件实际 ARM64 指令及明确的 UIKit/宿主边界模型。专项覆盖 7 种宽度、3 种高度、2 种加载地址，重复布局、主题切换、关闭恢复、文本越界和原有交互保持。旧 1.7.2 二进制在同一夹具中复现关闭裁剪、下一条文字越界和分类玻璃缺失。

Xcode 构建及完整验证结果以随包 VERIFICATION.json 和对应 Actions 记录为准。未在用户 iPhone 注入运行，未进行真实 UIKit 像素渲染验收，不能将构建和模型通过等同于实机已确认。

## 使用

用本包替换旧插件，移除旧 FanqieX/FanqieAdBlock 动态库后重新注入和签名；同一 App 只加载一份。dylib 不是可直接安装的 App。名称保持 FanqieX，只更新 test，不更改 main。
