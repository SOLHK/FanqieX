# FanqieX 1.78R31 本地测试版

适用番茄小说 7.4.3（7.4.3.33）。

用包内的 `FanqieX-1.78R31.dylib` 替换旧插件并重新注入签名。进入「插件设置 → 诊断与其他 → 导出日志」，整行均可点击，随后显示「正在生成日志…」。生成成功会打开系统分享面板。如果当时有其他页面挡住分享，导出行会显示「已生成，点按分享」。生成失败会在导出行显示错误。

旧菜单把导出动作绑在单元格里移过来的按钮上，点选单元格本身没有导出动作。R31 由原生列表行发起请求，直接使用现有诊断存储生成最近一小时的 JSON 日志。上一次对搜索退出的处理未解决用户设备上无反应的问题，设备当时的具体触摸或呈现状态未取得。

编译后的列表选择、导出请求、后台文件生成和回调经过离线检查。真实 iPhone 触摸和系统分享面板待复测。包内 `VERIFICATION.json` 包含实际检查结果。
