# FanqieX 1.78R15 测试版

适用番茄小说 7.4.3（内部版本 7.4.3.33）。请移除宿主里的旧 FanqieX 或 FanqieAdBlock 动态库，注入包内的 FanqieX-1.78R15.dylib 和 FanqieXExport.dylib，并对两份动态库和 App 重新签名。

- 宿主启用新版 UIKit 设计时，由系统分段控件处理拖动和选中。当前宿主开启了 UIKit 兼容模式，使用 `UIGlassEffect` 渲染拖动镜片。镜片开始拖动时抬起放大，松手后从释放位置平滑归位。
- 短剧顶栏在首次进入前应用分类与搜索开关。关闭搜索时，冷启动浮层也遵循该设置。
- 底栏高度会根据宿主底栏的可用空间调整。日志中的 74 pt 宿主底栏在最大高度下保留 12 pt 底部间距。
- 下载管理中，已完成下载的普通小说行会显示“导出”。可导出整本、最新一章或最近 N 章，支持 TXT、Markdown、HTML、EPUB、JSON，完成后打开系统分享面板。
- 导出按本地目录顺序读取已下载正文，使用宿主已有的解密接口。所选章节缺失、解密或解析失败时停止并提示，取消会清理此次临时文件。

核心界面修复与导出模块分别编译。导出模块采用 Objective-C ARC，配套检查涵盖本地章节读取和五种文件格式。实际注入后的导出入口、分享，以及底栏触感、折射和首帧显示需要 iPhone 验证。
