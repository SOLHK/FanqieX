# FanqieX 1.78R15 布局修复版

适用番茄小说 7.4.3（内部版本 7.4.3.33）。从 IPA 移除上一版 FanqieX、FanqieXExport 或 FanqieAdBlock 旧库及对应加载项，注入这份 FanqieX-1.78R15.dylib，然后按原流程重签插件和 App。保留现有应用数据即可。

安装包只有一份 dylib，含核心和本地小说导出。该库带有 `LC_UUID`，并通过初始化入口、导出模块注册、重定位和签名页检查。

- 在 FanqieX 设置的「阅读与书架」打开「导出书籍」，或搜索「导出」直接找到入口。页面列出本地已下载小说。
- 在「我的下载 → 已下载」里，已下载正文的小说行显示「导出」，与宿主的「管理」按钮并存。
- 整本导出需要全书下载完成。最新一章和最近 N 章按本地下载记录与原目录顺序选取，支持 TXT、Markdown、HTML、EPUB、JSON。只读取本地已下载章节，缺失章节、解密错误或正文解析失败会停止并提示。成功后打开 iOS 原生分享面板。
- 短剧首页隐藏横向搜索提示条。「显示短剧搜索按钮」仍控制独立放大镜。
- 短剧底栏接收从玻璃胶囊内部开始的拖动，进度条区域仍可拖动进度。沿用书架的玻璃拖动效果和底栏最大高度下的底部留白。

## 本次界面适配

- 短剧两套播放器的进度热区和底栏分开处理。从胶囊起手切换标签，在进度轨道起手仍可拖动播放进度。
- 「查看全集」的胶囊按当前进度轨道顶边留 8 pt。暂停或轨道变粗时会重新算位置，切换内容时不会因为旧的合集暂时共存而撤销当前间距。
- 短剧灰色横向搜索框在初次挂载时即隐藏。独立放大镜继续使用原有设置。
- 书架标题排和吸顶筛选排优先共用玻璃背景。宿主列表裁剪限制共用背景时，两排使用同一主题底色。首次显示时让普通文字和蒙版文字按胶囊居中。
- 切到历史后恢复宿主分页容器的位置，首排书封完整显示在顶栏下方，历史列表保留自身的滚动位置。
- 阅读底栏统一胶囊，名义 76 × 44 pt，较窄时一起收窄。沿用宿主的图标、标题和点击动作。

已通过已列出功能的 ARM64 离线专项验证，并在两个加载地址执行成品核心启动逻辑。实际玻璃画面、触摸和分享留待 iPhone 验证。
