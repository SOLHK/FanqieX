# FanqieX 1.78R15 测试版

适用番茄小说 7.4.3（内部版本 7.4.3.33）。请移除宿主里的旧 FanqieX 或 FanqieAdBlock 动态库，注入本包的 ARM64 动态库并重新签名。

- 宿主启用新版 UIKit 设计时，由系统分段控件处理拖动和选中。当前宿主开启了 UIKit 兼容模式，使用 `UIGlassEffect` 渲染拖动镜片。镜片开始拖动时抬起放大，松手后从释放位置平滑归位。
- 短剧顶栏在首次进入前应用分类与搜索开关。关闭搜索时，冷启动浮层也遵循该设置。
- 底栏高度会根据宿主底栏的可用空间调整。日志中的 74 pt 宿主底栏在最大高度下保留 12 pt 底部间距。

ARM64 构建、底栏交互与布局、短剧顶栏首帧回归在本地通过。实际触感、折射和闪现是否消失仍需 iPhone 验证。
