# FanqieX 1.6.2 设备观察点

构建与离线指令测试不包含用户设备的 UIKit 合成结果。安装时移除旧插件，
使用相同 IPA 注入与重签名方式载入 `FanqieX-1.6.2.dylib`，确保只加载一份插件。

| 操作 | 观察结果 |
| --- | --- |
| 完全退出再启动番茄小说，进入书架 | 时长、编辑和筛选的第一帧已经是完整胶囊，没有先出现矩形再变圆 |
| 打开小说后返回书架，连续重复几次 | 同上，返回动画中不闪矩形白底 |
| 在书架推荐区域滚动，让不同书封面经过底栏 | 整条底栏始终有磨砂底座，背景颜色可透入，文字能清楚辨认 |
| 切换底栏的全部栏目 | 选中强调层为半透明灰色，不是纯白块，实际页面与选中状态一致 |
| 从已选中和未选中栏目分别开始拖动，松手、取消 | 选择能跟手；松手进入对应页面；取消后回到正确状态 |
| 拖动期间等待周期刷新、再从其他入口返回首页 | 系统拖动预览不被刷新抢写，外部切页后状态及时同步 |
| 切换系统浅色、深色外观 | 底座与灰色选中层适应外观，文字保持可辨认 |
| 进入小说阅读顶部 | 返回、搜索等继续使用宿主原始控件 |
| 打开插件设置与导出日志 | 标题 FanqieX、版本 1.6.2；诊断可导出，旧设置与近期记录保留 |

如仍有闪动，屏幕录制应包含完整的“冷启动→书架”或“阅读→返回书架”过程；
同次会话导出的诊断可用于区分执行路径。静态截图只能定位位置，不能测量
亚秒闪动或动态折射。
