# FanqieX 1.8R7 测试版

基于 1.8R6，面向番茄小说 7.4.3（7.4.3.33）。

- 智能朗读顶部的收起和更多使用 42 pt 圆形玻璃。上一章、播放／暂停、下一章、目录和定时使用同样的深色玻璃底材。
- 点「我的」时，选中胶囊直接滑到目标位置并回弹，减少过渡中的亮度变化。
- 短剧右侧分享图标在窄屏内缩，为实心和空心样式留出边距。
- 在「插件设置 → 短剧 → 顶部分类」可分别关闭「看剧」「最近」「收藏」，支持沿用旧版保存的隐藏选择。
- 在「插件设置 → 页面与导航 → 底栏入口」可关闭「底栏点击震动」。开关默认开启。
- 短剧首次显示评论数时合并初始更新，显示当时最新的宿主计数。评论输入、图片和表情共用一条液态玻璃底座，各自保留原有操作。

在原有插件管理器中替换 `FanqieX-1.8R7.dylib`，退出番茄小说进程后重开。
