本次处理

1. 书架／我的：修正向下滚动后推荐列表没有延伸到底栏后面的布局。
   诊断记录中，屏幕高956pt，底栏从882pt开始；书架内层列表停在890pt，
   我的内层列表停在882pt。满足页面、视图类型、可见性及几何条件后，
   现在将列表延伸到窗口底部，并等量补偿底部滚动留白，保留最后一项的
   可滚动范围。宿主重复布局时同步修正；切页、滚回页头和关闭效果时恢复。

2. 底部选中态：静止时使用随系统外观适配的灰色胶囊填充；拖动时使用
   原生液态玻璃透镜。保持原按钮的事件路由，装饰层不接收点击。

3. 阅读返回键：仅处理明确属于阅读导航的返回图标。优先根据公开的图像
   对齐信息定位；信息不足时用系统返回符号统一可见图形。保留原点击区域。
   不具备相关API时保留原图；退出、禁用及宿主换图时按所有权恢复。

4. 阅读按钮延迟：消除静止布局中的重复圆角写入、图标玻璃尺寸往返、
   父子布局重复处理；为导航遍历设置总预算，并跳过玻璃及滚动内容子树。
   同时修复诊断日志按对象地址误判变化的问题，减少无变化的完整快照。
   新增 reader_layout / readerPluginLayoutMs 记录，只表示插件布局处理耗时，
   不代表真实的点击到响应时间。

4. 书架、我的分别滑到推荐列表较深处，再滚回页头并切换页面，检查底栏背后
