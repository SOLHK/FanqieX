# FanqieX 1.8R1

基于 1.79R5 提交 `d902d25751f616760dd8850a2e5acbdbc5ae8a5e`。适配番茄小说 7.4.3（7.4.3.33）arm64。

- 短剧顶部分类与搜索按当前窗口的顶部安全区定位。分类变化和布局刷新时重新对齐。
- 「我的」快捷入口使用正圆玻璃，给图标、文字和外层卡片留出上下空间。阅读段评在数字旁加入对话气泡图标，保留原生段评点击和特殊徽标。
- 双指清屏与原生长按快进、拖动进度分开处理。捏合完成后按原可见性恢复控件，保留宿主给控件设置的透明度。
- 开启「默认最高画质」后，按原生可用流的像素数和码率选档，并在播放器就绪后检查是否需要切档。当前视频的手动选档仍由宿主处理。
- 短剧推荐流刷到文本小说时，阅读入口和相邻信息随底栏位置向上避让。复用为视频卡片时还原。
- 底栏按压、拖动和松手使用连续的位置变化。松手的阻尼过渡同步收起折射层和恢复静止选中态。
- 智能朗读顶部按钮对齐两张底部卡片的外沿。功能栏内容增加两端留白，目录与定时的图标和文字居中，选中音色只显示圆角玻璃底。

安装前从宿主移除旧版 FanqieX，注入本版单个 dylib 后重新签名。真机复测包括两种屏幕尺寸的顶部位置、快进与清屏手势、横屏 1080P 实际播放、底栏连续点击与滑动动效，以及智能朗读页的对齐和选中态。
