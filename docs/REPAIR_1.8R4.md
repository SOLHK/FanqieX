# FanqieX 1.8R4

基于 1.8R3，面向番茄小说 7.4.3（7.4.3.33）。

- 书架筛选按钮绘制在相邻筛选选项上方，并清理右侧单独绘制的原生渐变层。使用原生书架背景。
- 段评采用圆润的空心气泡轮廓，外框完整包住玻璃，内部保留原有评论数。
- 智能朗读的导航、工具栏、播放和音色控件共用页面的深浅模式与玻璃材质。原生模糊封面铺满背景，清理卡片下方叠加的渐变。
- 「插件设置 → 短剧 → 播放设置 → 短剧右侧使用空心图标」可选用线条版的收藏、评论、点赞和分享。点赞和收藏用颜色提示已选中。开关默认关闭。
- 切到「我的」时，移动胶囊沿用落定选中态的底色，并继续执行滑移和回弹。

在原有插件管理器中替换为 `FanqieX-1.8R4.dylib`，退出番茄小说进程后重开。ZIP 内附验证记录。
