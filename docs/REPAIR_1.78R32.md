# FanqieX 1.78R32 本地测试版

适用番茄小说 7.4.3（7.4.3.33）。用包内的 `FanqieX-1.78R32.dylib` 替换旧插件后重新注入并签名。

- 短剧顶部的选中胶囊读取宿主分类标题的选中状态，玻璃明暗跟随已应用的页面背景。
- 推荐和漫剧的全集入口、详情页的原著章节入口与进度条之间预留 8 pt。间距写入宿主的布局约束，避免滚动、暂停或重新布局时贴边。
- 详情页的返回和更多使用同尺寸液态玻璃底，对准原按钮图标，保留原有点击范围和动作。

包内 `VERIFICATION.json` 记录了编译及离线验证结果。实际玻璃观感和触摸需在 iPhone 上验证。
