# FanqieX 2.0.1beta2

- 短剧顶部的「推荐」「看剧」「漫剧」点按会同步切换页面和选中状态。修复偶尔只播放选中动画的问题。
- 在「短剧 → 页面内容」新增「隐藏短剧标题入口」。开启后一起隐藏外流短剧的标题和右箭头，关闭可恢复。默认显示。
- 修复书架「历史」首次打开时，在默认分类已隐藏的情况下可能出现的空白。进入历史时会直接打开可见分类。
- 设置首页点击版本号可查看当前版本的更新。点击说明或「查看历代更新」，即可在下一级弹窗浏览此前版本的更新摘要。

使用 `FanqieX-2.0.1beta2.dylib` 替换原有 FanqieX 动态库，重新签名并安装。完全退出番茄小说后重新打开，在 FanqieX 设置首页核对版本号。
