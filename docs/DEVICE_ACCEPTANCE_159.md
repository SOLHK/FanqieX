## 安装后的版本核对

使用原有注入和重签名流程，以 `FanqieAdBlock-1.5.9.dylib` 替换旧插件。一个宿主进程只加载一份本插件，避免 1.5.8 与 1.5.9 同时改写相同入口。插件设置应显示 1.5.9；新导出的 JSON 顶层与当前会话事件也应显示 1.5.9。保留的一小时历史事件继续使用其真实旧版本，不应被改写。

## 列表与液态玻璃栏

1. 冷启动后分别进入书城、书架和“我的”，记录未滚动时的底栏。
2. 在书架和“我的”滑过顶部区域，继续上下滑动，检查内容能延伸至悬浮玻璃后面，原本整条固定白色缺口是否消失。记录发生异常时列表是否仍有后续内容。
3. 到列表末尾后再往上滑，检查末条内容仍可到达、没有跳动，底栏的点击和滑动切页正常。
4. 书架→我的→书城→书架反复切换，退出阅读页后再重复；检查第一次进入与后续进入一致。
5. 关闭玻璃功能再开启，检查原列表高度、内边距及裁剪恢复正常，没有累计扩展或滚动位置漂移。

## 阅读返回按钮

1. 检查箭头实际可见笔画的水平和垂直中心是否与圆形底板一致；截图需同时包含按钮圆环与箭头。
2. 多次进入阅读页、显示/隐藏菜单、切换日夜模式，确认没有重复布局后的位移累积。
3. 点击返回按钮和右侧各按钮，检查原点击区域及动作正常；记录首次显示与再次显示是否有明显延迟。
4. 检查阅读字体/界面缩放变化后仍然居中；若宿主支持 RTL，再单独记录该方向的结果。

## 诊断导出

若仍能复现，完成一次“进入目标页→滑动或打开阅读菜单→出现问题”的短操作后立即导出最近一小时日志，并保留同一时刻的截图或录像。新增诊断用于区分目标列表未被识别、祖先裁剪/布局改写、图标像素读取失败和实际位移结果。

原始设备日志可能包含界面上下文，继续通过任务附件提供；公开仓库只保存去标识的几何样例与合成测试结果。
