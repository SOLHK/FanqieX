# FanqieX 1.78R3 测试版

本版从 `SOLHK/FanqieX` 的 `test` 分支 1.78R2（`9b758c9793d6ef33d67e394e54d509ae2020cef7`）继续修复。
适配目标为番茄小说 7.4.3 / 7.4.3.33。测试版使用大写 R 并依次递增；正式版经用户确认后才进入 `main`。

## 本轮修复

用户反馈 R2 的“观看全集／观看完整漫剧”入口虽然避开了播放进度条，却被抬得太高，挤到了上方的作者声明和说明文字。

R2 使用进度控件的透明触摸容器作为避让边界，把没有实际显示内容的区域也计入了间隔。此次日志中，进度容器顶端为 851 pt，可见进度轨道顶端约为 873 pt，全集入口原底边为 876 pt；旧逻辑因此上移了 33 pt。

R3 改为按可见进度轨道定距，全集入口与轨道保留 **8 pt** 的小间隙。同一组坐标只需上移约 **11 pt**，比 R2 回落约 **22 pt**，减轻对上方说明的挤压。该数值说明此次日志所对应的布局，其他页面按其实际坐标计算。

进度条本身、原生触摸区域和拖动手势保持不变。重复布局继续从宿主位置计算，避免位移不断叠加；退出或目标复用时恢复宿主位置。

## 版本和安装

插件文件名、内部安装标识、设置页、诊断日志及构建报告统一为 **1.78R3**，并重新编译。

1. 移除旧的 FanqieX / FanqieAdBlock 动态库。
2. 使用 `FanqieX-1.78R3.dylib` 注入原宿主 IPA，再按原流程重签安装。同一宿主只加载一份插件。
3. 在设置或新导出的诊断中确认完整版本号为 1.78R3。

## 验证范围

构建流程使用 Xcode 27.2 / iOS 27.2 SDK 生成实际插件，随后校验同一提交的 Apple 产物、源码哈希和配套汇编，并执行候选 ARM64 指令回归、二进制结构、签名页及异常展开表检查。以对应提交 Actions 与交付包 `VERIFICATION.json` 的实际结果为准。

自动回归使用明确的 UIKit、Foundation 和宿主边界模型，不能代替真实 iPhone 上运行番茄小说。本轮未宣称已完成 iPhone 实机验收。

## 本轮设备检查

- 打开截图中的漫剧页面，检查“观看完整漫剧”入口只略高于进度条，上方作者声明和介绍完整可见。
- 拖动播放进度，再点击全集后返回，检查两处操作正常。
- 上下切换视频、调整底栏尺寸或触发底栏收缩后，检查间距保持稳定，没有越抬越高。
- 若仍有位置异常，导出 1.78R3 诊断并附当前页面截图。
