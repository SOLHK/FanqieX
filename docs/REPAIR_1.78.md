# FanqieX 1.78 测试版

本版对应番茄小说 7.4.3 / 7.4.3.33 的底栏与阅读界面调整。

## 本次修改

- 新增「底栏仅显示图标」开关。书城、短剧、书架、我的、商城、短句按实际入口名称映射系统符号，选中项使用对应填充符号。文字视觉隐藏后，原入口动作和无障碍朗读名称保留。无法识别的新入口优先保留宿主图标，没有可用图标时保留文字。
- 新增「短剧滚动自动收缩」开关。仅观察当前短剧页面原有的竖向滑动手势，浏览下一条时收缩，反向滑动时展开。切换页面、取消手势、关闭开关或离开可见窗口时复位。不开新的全局滚动 Hook，不替换原手势的代理。
- 新增底栏「胶囊长度」「胶囊高度」「按钮宽度」「图标大小」调节及一键恢复默认。按钮宽度指胶囊内按钮区域的宽度。设置过小时自动保留点击空间，避免按钮挤出胶囊或无法点击。
- 系统分段控件与备用按钮两种底栏路径均适配。短剧的局部深色外观也同步到备用按钮，防止浅色系统外观下图标对比度不足。
- 阅读页分享按钮沿用原点击或手势入口，补上液态玻璃。识别范围限于阅读导航栏的实际小型控件，以运行时类语义、无障碍标签或已注册分享动作确认身份。
- 阅读导航图标上限调整为 20 pt；普通工具文字、上下章文字、底部说明文字分别调整比例。个人页快捷入口图标上限 20 pt，保留原文字与动作。关闭玻璃后恢复原来尺寸和字体，后续宿主写入优先。
- 不修改正文阅读字号。纯图标和自动收缩默认关闭；尺寸默认 100%，图标默认 20 pt。

## 设置入口

打开番茄小说内的 FanqieX 设置，进入 **「底栏外观与尺寸」**。

| 项目 | 范围 | 默认 |
| --- | --- | --- |
| 底栏仅显示图标 | 开 / 关 | 关 |
| 短剧滚动自动收缩 | 开 / 关 | 关 |
| 胶囊长度 | 50%–100% | 100% |
| 胶囊高度 | 80%–125% | 100% |
| 按钮宽度 | 70%–100% | 100% |
| 图标大小 | 16–26 pt | 20 pt |

最小实际尺寸会随入口数量和可用空间调整，确保按钮至少保留 44 pt 的点击尺寸。系统分段控件负责原生选择和触摸，插件图标视图不接收触摸。

## 源码基线与验证边界

本次能够核验的公开源码基线为 `81a6a7cc88ec5c93c49bcc25e80051522b85ae52`（1.76）。用户上传日志来自 1.77r3，其完整源码不在当前仓库中。本次将日志明确记录的原生视频尺寸处理纳入 1.78：移除 1.76 的 `portraitVideoSize` 和播放器控制容器 `setFrame:` 改写，避免底栏外观调整重新引入视频尺寸变更。没有证据的 1.77r3 私有修改不宣称已完整继承。

自动验证执行候选插件的真实 ARM64 指令，UIKit、Foundation 与宿主对象是显式边界模型；它不是 iPhone 渲染或注入测试。构建来源、候选哈希及各项验证结果记录于包内 `VERIFICATION.json`。云端构建按同一源码提交核对 Xcode 产物及配套汇编，避免将 Linux 编译结果冒充 Apple 产物。

真实 iPhone 的玻璃折射、最终像素效果、触控体验及 IPA 注入仍需设备确认。分享入口若宿主变更且不再提供可识别信息，将保留原按钮并记录未匹配，不装饰无关控件。

## 安装与检查

先移除旧的 FanqieX / FanqieAdBlock 动态库，再注入 `FanqieX-1.78.dylib` 并重新签名。同一个宿主只加载一份插件。`.dylib` 不是独立安装的 App。

安装后可先检查：

1. 文字与图标模式互相切换，书城、书架、我的和短剧均能正常进入。
2. 打开自动收缩，在短剧里浏览下一条、反向滑动和切到其他页。
3. 调节三项尺寸，点击全部入口，再恢复默认。
4. 日间和夜间阅读时点击分享，检查原分享功能及上下章、目录、设置入口。
