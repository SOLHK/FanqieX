# FanqieX 2.0.1beta12 更新说明

## 本版更新

1. **修复听书主界面双层玻璃回归并精准覆盖全部二级半屏弹窗**
   - 严格排除听书主界面容器（`SSNestedContainerScrollView`、`FQRJXCategoryListContainerView`、`SSNewAudioPlay*`、`SSAudioPlayTTS*` 及包含“边听边读”的主播放区），不再给听书主界面原有液态玻璃叠加第二层玻璃卡片。
   - 移除主界面同时存在的单命中关键词（“音色设置”、“真人讲书”），改为严格匹配各二级弹窗专属元素，并在 `UIWindow -sendEvent:`（`UITouchPhaseEnded`）与触摸观察器取消态同步触发扫描，覆盖全部可见窗口与模态层级，精准为语速、已加书架、选择章节（下载）、章评、更多、简介/播放目录、定时关闭与音色设置二级半屏弹窗应用液态玻璃/模糊玻璃与自定义模糊度。

2. **「视频同款粉雾」更名为「柔性粉雾」**
   - 设置项与搜索关键词中统一将「视频同款粉雾」改名为「柔性粉雾」，保留原有哑光渐变粉雾选中色与设置兼容性。

3. **顶部按钮与 Dock 栏新增可选「粉雾玻璃」**
   - 保留真实 iOS 26 `UIGlassEffect` 透明液态玻璃折射，精准复刻参考视频同色系：
     - 外底色：透明粉雾瓷灰液态玻璃（`#EEE8EC` @ 42% + `0.5pt` 粉雾银边），深色/浅色背景下均保留清晰墨黑字标与透明折射；
     - 选中胶囊：真实交互式液态玻璃镜头叠加 5 段对角粉雾渐变（`#E0A6B6 → #DFB6C1 → #E2D3D8 → #E2E1E4 → #DFDEE2`）与左上角柔粉光晕及高光玻璃边。
   - 支持在「Dock 材质」、「顶部与短剧按钮底色」及「顶部按钮与 Dock 选中色」中自由选择「默认 / 柔性粉雾 / 粉雾玻璃」搭配，并同步适配短剧顶部分类、搜索按钮、右侧互动按钮、全集/原著/弹幕/全屏按钮及独立圆形底栏模块。
