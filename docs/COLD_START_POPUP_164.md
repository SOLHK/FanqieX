# FanqieX 1.6.4 冷启动首页广告候选

现场是彻底退出宿主后重新打开，书城已绘制，京东素材出现在带遮罩的首页弹层。现场导出显示过滤选项已开启。导出只记录底栏、插件启动和段评 Hook 快照，无法识别该素材的实际展示入口。

匹配 UUID 的宿主 7.4.3 在首页非标广告分发中调用 `+[SSCommonABTestHelper insert_screen_ad_pop_cfg]`。返回 true 时，宿主跳过 `showInsertScreenOfNonstandardAdMessage:showBlock:`，并走自己的标记已读分支。普通推荐、青少年模式及传统开屏有独立入口。

候选在开屏广告选项开启时安装精确类方法 Hook，校验 `B16@0:8` 并复用 1.6.3 的元类归属检查。实际调用产生 `adRuleDecision`，规则 ID 为 `homepage_nonstandard_popup`。事件只含静态规则字段、时间和队列序号。页面展示状态记录为 `unobserved`，事件不采集广告素材、个人信息或网络内容。

## 验收

1. 在同一台 iPhone 和宿主上移除旧插件，重新注入并开启「开屏广告」过滤。
2. 彻底退出宿主，再打开书城。对照弹层是否出现，导出 JSON 并查找 `homepage_nonstandard_popup`。
3. 核对书城可立即操作，普通推荐、阅读和段评路径仍可用。
4. 关闭过滤并重启，核对插件不安装该规则。素材下线或投放条件变化时，单次没有展示无法验证规则。

离线回归覆盖开关、签名不匹配、继承保护、其他配置方法保留及实际诊断写入。京东素材是否走该路径、是否消失、宿主启动延迟仍待真机验证。
