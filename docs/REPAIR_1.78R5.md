# FanqieX 1.78R5 测试版

基于 `SOLHK/FanqieX` 的 `test` 分支 1.78R4（`29f8b5957625a5a142ec379d9d618c1405a1e156`），修复自定义底栏尺寸后点击、滑动不稳定的问题。适配目标为番茄小说 7.4.3 / 7.4.3.33。

## 本轮修复

### 自定义尺寸在写入界面前统一计算

用户反馈使用胶囊长度 100%、高度 110%、按钮宽度 100%、图标 28 pt，同时开启纯图标及短剧自动收缩后，底栏点不动、划不动。

对 R4 实际 ARM64 产物的回归复现确认：宿主原布局在原有按钮、胶囊 frame 入口写入默认尺寸，随后插件再改成自定义尺寸。110% 高度下，胶囊在一次宿主布局内先回到 56 pt，再变成约 61.67 pt；原来的测试只检查布局完成后的坐标，没有发现中间反复缩放。

R5 在现有两个 frame 适配入口直接计算最终尺寸，让原始的“坐标相同则不写入”路径看到最终坐标。稳定尺寸下再次宿主布局不会先恢复默认再缩放，原生选择控件可继续持有同一个触摸跟踪对象。胶囊、图标按钮和原生选择区域继续使用一致的布局规则。

原始尺寸和实际应用尺寸分别保存。宿主更新窗口或底栏布局时采纳新的原始坐标；恢复默认或关闭插件时使用当前原始尺寸，避免缩放累积或恢复旧窗口的坐标。按钮与胶囊间使用弱关联，移除、替换和关闭时清理关联。

### 滑块与滚动回调不再强制同步布局

尺寸滑块保存规范化的数值后，申请下一次正常 UIKit 布局；连续输入中相同的取整数值不再重复刷新。短剧自动收缩、恢复默认也使用正常布局调度，避免在正在处理滑块或滚动手势时嵌套强制布局。

R4 的胶囊外透明背景和 28 pt 默认图标继续保留，R3 的全集入口小间距继续保留。

## 安装和复测

1. 替换旧 FanqieX / FanqieAdBlock 动态库，注入 `FanqieX-1.78R5.dylib`，按原流程重新签名安装；同一宿主只加载一份插件。
2. 完全退出再打开番茄小说，在设置或诊断日志中确认版本为 **1.78R5**。
3. 直接保留原来的 100% / 110% / 100% / 28 pt 设置，连续点击底栏各入口并左右拖动选中项。
4. 在短剧页上下滑动，确认自动收缩与展开后仍可切换入口；再调整长度、高度、按钮宽度，确认触摸区域跟随尺寸。
5. 点击“恢复底栏默认设置”，检查尺寸恢复与点击、滑动。

## 验证范围

新增回归执行实际候选 ARM64 的按钮 frame 适配、胶囊 frame 适配、原始坐标写入及完整底栏修复路径，记录每一次中间 frame 写入。覆盖原生选择和按钮回退两种渲染器，截图尺寸与较小/较大组合、正在跟踪的选择预览、一次操作只触发一次原始选页、宿主窗口变化、恢复原始尺寸，以及滑块和短剧滚动回调不强制同步布局。

R4 的相同回归可以复现失败。自动测试中的 UIKit、Foundation、宿主接口是显式边界模型；不能据此声称已完成 iPhone 上实际点击、拖动与玻璃渲染验收。用户日志确认事件仍在返回，但没有触点坐标或 UIKit 取消原因，因此本版针对可复现的尺寸覆盖及同步布局冲突修复，设备表现仍需按上面步骤验收。

发布继续使用 Xcode 27.2 / iOS 27.2 SDK，并校验同一提交的源码、内部 R5 版本、真实 Apple 产物、签名页及展开表。R5 沿用 R4 的 `0x40000` 扩展容量上限。实际通过结果以对应提交 Actions 和包内 `VERIFICATION.json` 为准。

测试修改只推送 `test`；正式版经用户确认后才进入 `main`。
