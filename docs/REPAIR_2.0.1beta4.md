# FanqieX 2.0.1beta4

「短剧滚动自动收缩」恢复单圆按钮样式，沿用此前设置的收缩位置。尚未选择位置时，默认收在右侧。

「页面与导航 → 底栏入口」新增「刷视频时自动缩放 Dock」。刷下一条视频时，多个底栏图标一起缩小并居中。往回翻看或在当前视频上轻提后松手，Dock 恢复正常尺寸。两种模式分别保存，开启其中一种会关闭另一种，全新安装时均为关闭。

新模式按拖动速度启动回弹。纯图标底栏收起时，每个图标缩到原尺寸的 90%，快速反向时从屏幕上正在显示的位置继续。

使用 `FanqieX-2.0.1beta4.dylib` 替换旧版 FanqieX 动态库，重新签名并安装。在 FanqieX 设置首页可核对版本号。
